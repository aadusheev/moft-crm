# Вход CRM

CRM использует собственную серверную сессию. Заголовки oai-authenticated-* и старые cookies Sites больше не дают доступ. Главная страница требует вход; обе CRM API проверяют сессию, настройки — роль owner. Отключён mockAuth в dev-сборке.

Пароли: scrypt N=32768, r=8, p=3 с отдельной случайной солью. Сессия: 256 случайных бит, только SHA-256 токена в базе, 8 часов, Secure / HttpOnly / SameSite=Strict / __Host cookie. POST проверяет Origin. Лимит входа — 10 попыток на email и 100 суммарно за 15 минут, состояние в базе. Публичной регистрации нет.

Таблицы crm_auth_* создаются идемпотентно при первом использовании через существующий D1 binding. Клиенты, события, продажи, настройки моста не изменяются и не пересоздаются. Отдельного секрета сессий или ручной миграции для входа не требуется. Сохранность базы при redeploy остаётся обязанностью действующего серверного процесса; не меняйте путь persist.

Первый владелец использует секретную одноразовую ссылку. В репозитории owner-bootstrap.json содержит только хеш случайного 256-битного кода, фиксированный email и срок действия. Сам код хранится вне Git; пароль выбирает владелец. После создания аккаунта код не может изменить пароль или создать второй аккаунт. Ссылка передаёт код во fragment, который страница сразу убирает из адреса; запросы с паролем/кодом нельзя логировать. Не публикуйте секретную ссылку.

Владелец может создать приглашение сотруднику в «Доступ сотрудников». Приглашение привязано к email, действует 7 дней и используется один раз. Повторное приглашение до регистрации заменяет старое. Оно даёт роль staff, не owner. Письма автоматически не отправляются. Восстановление забытого пароля пока выполняет администратор сервера; открытого сброса/повторной регистрации нет.

После публикации проверить: анонимные CRM API и auth GET — 401; главная перенаправляет на /login; поддельные oai-заголовки не помогают; владелец может менять источник, сотрудник получает 403; выход отзывает сессию. Вход и выход не удаляют данные. После этого подключать MOFT.RACE через существующее окно. Не включать обход входа в прокси или локальные патчи, заменяющие lib/crm-auth.ts.
