# Перенос CRM

Текущее состояние: исходники рабочей версии с входом ChatGPT. Вход по email/паролю и запуск на отдельном сервере ещё не реализованы. Этот репозиторий — подготовленный исходный пакет, а не завершённый перенос.

## Данные

В репозитории нет клиентской базы, резервных копий, паролей или ключа моста. Хранить их отдельно от GitHub. Сохранять исходные ID клиентов, external_id, событий и продаж, суммы в минимальных денежных единицах, actor и даты. Не импортировать лист Google заново вместо полной CRM-базы: в листе нет истории CRM и отдельных продаж.

Офлайн-проверка восстановления (Node.js 22.13+):

    node scripts/restore-backup.mjs /secure/backup.json /secure/new-database.sqlite

Скрипт откажется перезаписывать файл, восстановит четыре таблицы одной транзакцией и сравнит SHA-256 всех полей каждой таблицы. Результат проверки не содержит данных клиентов. Не размещать созданную SQLite-базу в web/public, GitHub или архиве исходников.

## Переключение

1. Подготовить отдельную версию с email/паролем, закрытой регистрацией сотрудников, серверной проверкой сессии, выходом и ограничением попыток входа.
2. Настроить сервер, HTTPS, резервное копирование и секреты вне репозитория. Не публиковать базу или служебные endpoints.
3. Проверить восстановление и UI на отдельной базе. До переключения выключить запись этой тестовой версии в MOFT.RACE, чтобы не было двух одновременно работающих CRM.
4. На время финального снимка остановить изменения в старой CRM, выгрузить свежие четыре таблицы и сверить их с восстановленной базой. Текущий подготовительный снимок не заменяет финальную выгрузку.
5. Перенести MOFT_BRIDGE_URL и MOFT_BRIDGE_SECRET через защищённые настройки сервера. Apps Script продолжает использовать тот же HMAC-протокол, исходный файл и запись только трёх полей.
6. Проверить вход владельца и Тимура, запрет анонимного чтения/записи, события с правильным автором и обмен в обе стороны. Проверочную заметку вернуть в исходное состояние.
7. Только после сверки переключить рабочую ссылку. Старую CRM и её базу сохранить для отката; не допускать одновременной рабочей записи в двух версиях.

GitHub хранит код; GitHub Pages не заменяет сервер CRM с базой и авторизацией.
